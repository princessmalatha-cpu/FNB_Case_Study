Retail Sales Analytics Dashboard
Overview
This project is an interactive Retail Sales Analytics Dashboard developed as part of a Data Analyst Sales Case Study.

The dashboard transforms daily retail trading data into an executive-friendly analytical experience covering:

Sales performance
Pricing
Profitability
Promotion performance
Price elasticity of demand
Business insights
Underlying data exploration

The dashboard is designed to demonstrate practical data analysis, KPI development, data visualization, and business storytelling.
Dataset
The primary data source is:

FNB_Sales.xlsx

The case study describes the dataset as simulated daily trading information for a large retail store, covering one product. Each record contains:

Date — the day on which sales occurred
Sales — total Rand value of sales
Cost of Sales — total Rand value of cost of sales
Quantity Sold — total number of units sold

The case study requires the analysis to derive additional metrics and insights from these fields. fileciteturn0file0L8-L15
Business Objectives
The dashboard addresses the analytical requirements in the case study:

Calculate daily sales price per unit.
Calculate the average unit sales price.
Calculate daily gross profit percentage.
Calculate daily gross profit percentage per unit.
Identify three promotional periods.
Calculate price elasticity of demand for each selected promotional period.
Assess promotional-period performance using the underlying data.
Identify additional meaningful insights, KPIs, reports, and visualizations.
